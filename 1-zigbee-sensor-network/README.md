# 信链农擎 ZigBee 无线传感网

基于 TI CC2530 与 ZStack 协议栈开发的 ZigBee 无线传感器网络，是"信链农擎——农事数据治理平台"的物联网设备层。

## 系统架构

```
终端节点(Slave) ──ZigBee──> 协调器(Master) ──串口──> PC上位机 / WiFi网关 ──> 手机端
   (传感器采集)              (汇聚+显示+报警)
```

- **终端节点**：采集温湿度、空气质量、一氧化碳、光照等多路环境传感器数据
- **协调器**：汇聚多终端数据，OLED 显示，温湿度超标蜂鸣器报警
- **网关**：数据转发，串口上传

## 技术要点

- 基于 TI ZStack 协议栈，采用 OSAL 任务调度 + 定时器实现周期采集
- 手写单总线（DHT11）、I2C（OLED）等传感器底层驱动
- 自定义 8 字节串口通信协议（含校验和）
- UART / RF 中断收发数据
- 温湿度超标蜂鸣器报警

## 目录结构

```
├── coordinator/      # 协调器代码（协议 + 主程序）
├── router/           # 终端/路由节点代码
├── gateway/          # 网关代码
├── pc-upper-machine/ # PC 上位机（MFC）
└── android-app/      # Android 手机端
```

本项目基于 TI ZStack 协议栈开发，本仓库仅包含自行编写的应用层代码，协议栈源码需从 TI 官网获取。
