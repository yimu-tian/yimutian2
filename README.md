# 嵌入式项目集 Embedded Projects

物联网工程专业学生的嵌入式开发项目集，涵盖 ZigBee 无线传感网、物联网云平台、数字电路设计三个方向。

## 项目列表

| 项目 | 技术栈 | 目录 |
|------|--------|------|
| 信链农擎 ZigBee 无线传感网 | CC2530 + ZStack 协议栈 | [1-zigbee-sensor-network](1-zigbee-sensor-network/) |
| 物联网云平台（MQTT） | 阿里云 linkkit + OneNET MQTTnet | [2-iot-cloud-platform](2-iot-cloud-platform/) |
| Verilog 8 位 CPU | SystemVerilog | [3-verilog-cpu](3-verilog-cpu/) |

## 技能概览

- **MCU 开发**：STM32/GD32、CC2530（8051 内核）
- **通信协议**：ZigBee（802.15.4）、UART、I2C、SPI、MQTT
- **开发工具**：Keil MDK、IAR Embedded Workbench、STM32CubeMX
- **编程语言**：C/C++、Python、C#、SystemVerilog、MATLAB
